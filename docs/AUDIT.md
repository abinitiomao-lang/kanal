# Аудит YouTube API (снимает лок «private»)

Подаётся после того, как канал работает 1–2 недели и есть опубликованные видео.

1. Форма: https://support.google.com/youtube/contact/yt_api_form → «YouTube API Services — Audit and Quota Extension».
2. Что указать (черновик, я подстрою под факты на момент подачи):
   - **Тип клиента:** внутренний инструмент владельца канала, не публичный сервис; единственный пользователь — владелец.
   - **Назначение:** загрузка собственных образовательных видео на собственный канал; модерация каждого видео
     владельцем вручную перед публикацией (Telegram-апрув).
   - **Используемые методы:** videos.insert, videos.update (privacyStatus), videos.delete, thumbnails.set, videos.list.
   - **Данные:** не собираем и не храним данные других пользователей; OAuth-токен только в GitHub Secrets.
   - **Квота:** текущей достаточно, увеличение не запрашиваем.
   - Ссылки: репозиторий (публичный), Privacy policy (`docs/PRIVACY.md`), Terms (`docs/TERMS.md`).
   - Скринкаст 1–2 мин: бот присылает видео → кнопка «Опубликовать» → видео на канале. Запишу сценарий, когда дойдём.
3. Срок ответа — обычно от нескольких дней до нескольких недель. Могут попросить уточнения — пересылай мне.
4. После одобрения: `pre_audit_mode: false` в `config.yaml` — и кнопка «Опубликовать» начнёт публиковать сама.
