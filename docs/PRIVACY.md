# Privacy Policy — kanal uploader

kanal uploader is a private tool used solely by the owner of one YouTube channel to upload and manage
that channel's own videos via the YouTube Data API.

- It accesses only the owner's own YouTube channel, with the owner's consent (OAuth).
- It does not collect, store, sell or share personal data of any other user.
- OAuth credentials are stored encrypted as GitHub Actions secrets and used only to upload, update,
  delete and set thumbnails for the owner's videos.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
- This tool uses YouTube API Services; see the Google Privacy Policy: https://policies.google.com/privacy
  and YouTube Terms of Service: https://www.youtube.com/t/terms.

Contact: open an issue in this repository.
